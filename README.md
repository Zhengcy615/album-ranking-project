# Album Ranking Project

这是我的第一个 GitHub 实际项目。

## 项目目标

- 整理 RYM 前 100 专辑
- 整理 AOTY 前 100 专辑
- 标记我已经收藏的专辑
- 区分实体购买状态
- 检查榜单中的重复和错误
- 生成香港唱片店购买候选清单

## 收藏状态

- 已收藏，可以买实体
- 已收藏，不准备买实体
- 已收藏，已有实体
- 尚未收藏
